## 1. 출원 전 다시 검색 (KIPRIS, 10분)
1. kipris.or.kr → **상표** 검색
2. 검색어 4가지를 차례로 넣어요: `Shall We Dog` · `쉘위독` · `셸위도그` · `SHALLWEDOG`
3. 결과에서 **9류 · 41류**(상품분류 칸)이고, 상태가 '출원' · '등록'인 것을 봐요.
- ✅ 성공 (진행): 같은 글자이거나 거의 같은 상표가 9 · 41류에 **없음** → 2단계로.
- ⛔ 멈춤: 비슷한 상표(예: 'Shall We Dance' 계열이 게임 · 소프트웨어류에 등록)가 있으면 출원하지 말고 화면을 캡처해 탭 3에 보여 주세요. 거절되면 출원료는 돌려받지 못해요.
- 지난번 검색 결과와 같은지 날짜를 적어 둬요: 검색일 ____ / 비슷한 것 ____건

## 2. 특허로 회원 · 고객번호 (처음 한 번)
1. 특허로 → **회원가입** → 인증서 등록
2. **특허고객번호 부여 신청**(출원인 코드) [화면 확인] — 개인으로, 이름 · 주소는 사용자가 직접
- ✅ 성공: '특허고객번호'(숫자 12자리 안팎)가 화면이나 문자로 와요. 보통 바로 나오지만 하루 걸릴 수 있어요. **11/3까지는 이 단계를 끝내요.**

## 4. 출원서 쓰기 (약 40분)
1. 특허로 → **전자출원** → **상표** → **상표등록출원서** [화면 확인] (온라인 작성 또는 서식작성기)
2. 칸 채우기
   - 출원인: 2단계의 특허고객번호 (사용자가 직접)
   - 상표 유형: **일반 상표**, 견본 = 0단계 JPG
   - 상표 설명 · 색채: 없음(흑백)
   - 류 구분: **9류**와 **41류**를 각각 더해요.
   - 지정상품: 아래 후보에서 고르되, **특허로 '지정상품 검색'에서 고시명칭으로 나오는 것만** 넣어요(고시명칭이면 옆에 표시가 붙어요 [화면 확인]).
3. **제출** → 전자서명
- ✅ 성공: **출원번호**(40-2026-…)와 **접수증**이 나와요. 접수증 PDF를 저장해요.
