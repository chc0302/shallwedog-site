# 출시 전 보안 점검 (10/27 탭 3)

## 1. 사이트 보안 설정 (호스팅: GitHub Pages)
GitHub Pages는 응답 헤더를 바꿀 수 없어요. 그래서 페이지 안 `<meta>`와 작은 스크립트로 할 수 있는 만큼만 했어요.

| 항목 | 지금 | 이번에 한 것 | 남는 것 |
|---|---|---|---|
| HTTPS 강제 | ✓ http로 오면 https로 넘김 (인증서 2027-01-18까지) | — | — |
| HSTS (항상 https로만) | ✗ GitHub Pages가 보내지 않음 | 메타 태그로는 안 돼요 | 호스팅 앞단 필요(아래) |
| CSP (허락한 곳의 파일만 실행) | ✗ | **메타 CSP 넣음**. 우리 사이트 · 글꼴 CDN(jsdelivr)만 허락, 그 밖의 스크립트 · 틀 · 폼 막음. `upgrade-insecure-requests` | 메타 CSP는 `frame-ancestors`를 못 써요 |
| 다른 사이트 안에 띄우기 막기 (클릭재킹) | ✗ | **`/assets/js/frame.js` 넣음**: 틀 안에 들어가면 이 페이지로 빠져나와요 | `X-Frame-Options`, `frame-ancestors`는 헤더로만 돼요. 우리 사이트엔 폼 · 로그인이 없어 위험은 낮아요 |
| Referrer-Policy | ✗ | **메타로 `strict-origin-when-cross-origin`** | — |
| X-Content-Type-Options | ✗ | 메타로는 안 돼요 | 헤더 필요 |
| 인라인 스타일 | 404에 1곳 | CSS 클래스로 옮김 (CSP에 'unsafe-inline' 안 쓰려고) | — |

- 확인: 크롬으로 첫 화면 · 처리방침 · 영어 약관 · 404를 열어 봤어요. 글꼴과 스타일이 그대로 나오고 CSP 위반 기록이 없었어요.

### 헤더까지 하려면: 호스팅은 옮기지 않았어요. 방법과 비용만 적어요.
| 방법 | 비용 | 할 일 | 주의 |
|---|---|---|---|
| A. **Cloudflare 무료 플랜**을 GitHub Pages 앞에 두기 | 0원 | 가비아 네임서버를 Cloudflare로 바꾸고, 규칙(Transform Rules)으로 헤더 추가 | **메일 DNS(MX · TXT)까지 Cloudflare로 옮겨야 해서 Zoho 메일이 끊길 위험.** 옮길 때 기록을 똑같이 복사해야 함 |
| B. **Cloudflare Pages** 또는 **Netlify 무료**로 사이트만 옮기기 | 0원 | 저장소 연결, `_headers` 파일 하나, 가비아에서 A · CNAME(사이트 줄)만 바꿈 | MX · TXT는 그대로라 메일 영향 없음. 사이트 주소 확인(인증서) 몇 분 |
| C. 그대로 두기 | 0원 | — | 정적 페이지 · 폼 없음이라 실제 위험은 낮음 |
→ 추천: 출시 전엔 C, 출시 뒤 여유 있을 때 B.

## 4. hello@shallwedog.com 메일 위조 막기 (조회만 했어요. DNS는 건드리지 않았어요)
| 항목 | 지금 | 판정 |
|---|---|---|
| MX | mx.zoho.com · mx2 · mx3 | ✓ |
| SPF | `v=spf1 include:zohomail.com ~all` **앞에 탭(빈칸) 한 글자가 붙어 있음** | ⚠ 규칙상 SPF는 `v=spf1`로 바로 시작해야 해요. 앞의 빈칸 때문에 SPF로 안 읽힐 수 있어요 |
| DKIM | 흔한 선택자(zmail 등 8개)로 조회해 봤는데 없음 | ✗ 없는 것 같아요 |
| DMARC | `_dmarc` 기록 없음 | ✗ |

### 사용자가 할 일 (가비아 DNS 관리 + Zoho 관리 화면)
1. **SPF 고치기:** 가비아 > DNS 관리 > shallwedog.com > TXT 줄 중 `v=spf1`로 시작하는 줄을 수정해요.
   - 값 맨 앞의 빈칸을 지우고 `v=spf1 include:zohomail.com ~all`로 저장해요.
   - 줄을 새로 만들지 말고 그 줄만 고쳐요.
2. **DKIM 켜기:**
   1. Zoho Mail 관리 콘솔(mailadmin.zoho.com) > 도메인 > shallwedog.com > 이메일 구성 > **DKIM** > 추가로 가요.
   2. 선택자 이름을 `zmail`로 해서 만들어요.
   3. 나온 TXT 값을 복사해요.
3. 가비아에 TXT 줄을 추가해요. 호스트는 `zmail._domainkey`, 값은 2에서 복사한 것을 붙여요.
4. Zoho 화면으로 돌아가 **확인(Verify)** → **사용(Enable)**을 눌러요. DNS가 퍼지는 데 몇 시간 걸릴 수 있어요.
5. **DMARC 넣기:** 가비아에 TXT 줄을 추가해요.
   - 호스트: `_dmarc`
   - 값: `v=DMARC1; p=none; rua=mailto:hello@shallwedog.com`
   - 처음 2주는 `p=none`(보고만)으로 둬요.
6. 2주 뒤 보고 메일에 이상이 없으면 `p=quarantine`으로 바꿔요. 이러면 위조 메일이 스팸함으로 가요.
7. 끝나면 "메일 보안 다 했어"라고 알려 주세요. 다시 조회해 볼게요.
