# 가비아 로그인 2단계 인증 켜기 (10/27 탭 3)

가비아 계정에는 도메인(shallwedog.com)과 DNS가 들어 있어요. 이 계정을 빼앗기면 사이트와 메일(hello@)이 함께 넘어가요. 그래서 2단계 인증을 켜 두는 게 좋아요.

**가비아에 있어요.** 가비아 공식 고객센터 'My가비아 > 보안 설정' 안내에 아래 항목이 있어요(목차로 확인):
- 2단계 OTP 인증 설정하기 · 해지하기
- 로그인 기록 조회 · 허용/차단 IP 설정 · 해외 로그인 차단 · 정보 변경 알림

다만 고객센터 화면은 자바스크립트로 그려져서 세부 단계 글은 자동으로 읽지 못했어요. 아래 3~6번은 보통의 OTP 설정 순서예요. 화면 글자는 조금 다를 수 있어요.

## 사용자가 할 일
1. 폰에 OTP 앱을 깔아요. 예: Google Authenticator(Google OTP), Microsoft Authenticator.
2. 컴퓨터로 https://www.gabia.com 에 로그인 → 위쪽 **My가비아** → **회원 정보 / 보안 설정**으로 가요. 바로 가는 주소: https://mypage.gabia.com/myinfo/security
3. **보안 설정**에서 **2단계 OTP 인증 → 설정**을 눌러요.
4. 화면에 QR 코드가 나오면 OTP 앱의 **[+] → QR 코드 스캔**으로 찍어요.
5. OTP 앱에 나온 6자리 숫자를 가비아 화면에 넣고 **확인**을 눌러요.
6. 복구 코드나 백업 방법이 나오면 종이에 적거나 비밀번호 관리 앱에 보관해요. **폰을 잃어버렸을 때 필요해요.**
7. 같은 보안 설정 화면에서 아래 두 가지도 켜 두면 좋아요.
   - **해외 로그인 차단**
   - **정보 변경 알림**: 비밀번호나 DNS가 바뀌면 문자 · 메일이 와요.
8. 로그아웃했다가 다시 로그인해서 OTP 숫자를 묻는지 확인해요.

## 주의
- DNS 기록(MX · TXT · A)은 이 작업에서 건드리지 않아요. 로그인 보안만 바꿔요.
- 폰을 바꿀 때는 OTP 앱을 먼저 새 폰으로 옮긴 뒤 예전 폰을 초기화해요.
