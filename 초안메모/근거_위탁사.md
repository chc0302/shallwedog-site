# 위탁사 표기 근거 (10/27 3차, 탭 3)

## OpenAI
- 적은 것: OpenAI OpCo, LLC (미국) · privacy@openai.com. 사용자가 OpenAI 공식 '대한민국 이용자를 위한 개인정보 처리방침 부록'을 브라우저로 확인함 (https://openai.com/policies/kr-privacy-policy-addendum/).
- **국내대리인은 우리 방침에 안 적음.** 근거: 법 28조의8 ②이 방침에 적으라는 것은 ① 이전 항목 ② 나라 · 시기 · 방법 ③ 받는 자의 이름(법인명)과 연락처 ④ 받는 자의 이용 목적 · 보유 기간 ⑤ 거부 방법과 효과 다섯 가지예요. 국내대리인(법 31조의2)은 한국에 주소가 없는 처리자가 **자기** 처리방침에 적는 의무라, OpenAI 자기 방침(부록 10조)에 이미 있어요. 우리는 국외 이전 받는 자의 '연락처'만 적으면 돼요. (전문가 질문 7번에 함께 확인)
- OpenAI 부록 10조의 국내대리인 정보는 위 링크에서 바로 볼 수 있어요.
- 탭 4 재료(처리방침_재료.md)는 `OpenAI, L.L.C.`로 적혀 있어요 → 탭 4에 `OpenAI OpCo, LLC`로 맞춰 달라고 알리기.

## Zoho
- 적은 것: Zoho Corporation Pte. Ltd. (싱가포르, 저장은 미국) · privacy@zohocorp.com.
- 근거: 결제 화면에 나라가 따로 나오지 않음. 사용자는 한국에서 한국 카드로 결제. Zoho 약관(https://www.zoho.com/terms.html)은 계약 법인을 따로 표로 둠 → https://www.zoho.com/legal/zoho-contracting-entities.html — 한국은 표에 없어서 마지막 줄 '위에 없는 모든 나라 = Zoho Corporation Pte. Ltd.(싱가포르)'에 해당. 표는 예고 없이 바뀔 수 있다고 적혀 있음. 데이터 위치는 계정 주소가 mail.zoho.com(미국 데이터 센터) → https://www.zoho.com/know-your-datacenter.html
- 사용자 확인으로 '확인 필요'는 뺌.
