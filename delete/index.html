계정·데이터 삭제

Shall We Dog? 계정과 게임 데이터는 아래 두 방법 중 편한 쪽으로 지울 수 있어요.

방법 1. 앱 안에서 지우기

  1. Shall We Dog? 앱을 열어요.
  2. 화면 위쪽의 톱니바퀴 설정을 눌러요.
  3. 맨 아래 작은 글씨 줄의 데이터 삭제 요청을 눌러요.
  4. 한 번 더 누르면 삭제가 요청되고, 서버 데이터가 지워져요. 로그인되지 않은 폰이면 서버에 데이터가 없어서 이 안내가 열려요.

방법 2. 이메일로 요청하기

앱을 지웠거나 앱을 열 수 없을 때는 이메일로 요청해 주세요.

  1. hello@shallwedog.com으로 메일을 보내요.
  2. 제목에 ‘계정·데이터 삭제 요청’이라고 적어요.
  3. 본문에 쓰시는 기기(아이폰·안드로이드)와 게임센터·구글 플레이 게임즈의 게임 닉네임을 적어요. 커스텀 주문을 했다면 주문 번호나 스토어 영수증의 주문 번호도 적어 주세요.

본인 확인을 위해 몇 가지를 더 여쭤볼 수 있어요. 확인되면 지우고, 끝나면 메일로 알려드려요.

지워지는 것 (서버)

  • 계정 정보 (게임센터·구글 플레이 게임즈 로그인 정보)
  • 커스텀 강아지 다시 받기 (완성 파일)
  • 커스텀 주문 기록과 제작 기록, 아직 남아 있는 주문 사진
  • 앱 알림을 보내는 데 쓰는 기기 정보

남는 것

  • 이 기기 안의 게임 데이터는 그대로 남아서 계속 할 수 있어요. 기기에서도 지우려면 앱을 삭제해 주세요.
  • 계정을 지워도 법으로 정한 거래 기록(주문·결제·동의 기록. 사진과 완성된 강아지는 빼요)은 계정과 연결을 끊고 정해진 기간(5년, 불만·분쟁 기록은 3년) 따로 보관한 뒤 지워요.
  • 사고에 대비한 백업(주문·계정 정보, 사진은 빼요)에는 사본이 최대 30일 남았다가 자동으로 지워져요.

로그인되지 않은 채로 하셨다면 서버에 계정이 없어서, 앱을 삭제하면 기기 안 데이터가 함께 지워져요. 메일로 요청하시면 받은 날부터 5일 안에 지우고 끝나면 알려드려요. 한 번 지운 데이터는 되돌릴 수 없어요. 자세한 내용은 개인정보처리방침을 봐 주세요.
