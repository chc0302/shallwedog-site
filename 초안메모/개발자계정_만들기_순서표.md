# 개발자 계정 만들기 순서표 — AdMob → Play Console → Apple (탭 3, 10/28 15차)

오늘 위에서부터 차례로 해요. 모두 **hello@shallwedog.com 구글 계정**(2단계 켬)으로 시작해요. Firebase는 탭 4 `계정_생긴_날_순서표.md`대로 따로 해요.
- **굵은 글씨** = 누를 곳. 메뉴 이름은 한국어 화면 그대로이고, 괄호 안은 영어 화면 이름이에요.
- ✅ = 이게 보이면 성공이에요.
- 표시: 🌐 = 스토어에 공개돼요 · 🇰🇷 = 한국 사용자에게만 공개 · 🇪🇺 = EU 스토어에 공개 · 🔒 = 공개 안 됨(회사 · 스토어만 봄)
- `[ 직접 ]` 칸은 이 종이에 쓰지 않고 화면에 바로 넣어요. 옆에 그 값이 **어디 있는지**만 적었어요.
- 화면이 바뀌는 일이 잦아서 [화면 확인]이 붙은 곳은 비슷한 이름을 찾아 주세요.

## 0. 시작 전에 옆에 펴 둘 것
| ☐ | 무엇 | 어디 있는 값인지 |
|---|---|---|
| ☐ | D-U-N-S 번호 · 영문 상호 · 영문 주소 | D&B(D-U-N-S) **발급 메일** — 글자 · 띄어쓰기 · 쉼표까지 그대로 복사해 붙일 거예요 |
| ☐ | 사업자등록번호 · 상호 · 사업장 주소(한국어) | 사업자등록증 |
| ☐ | 투넘버 전화번호 (문자 받을 수 있게) | 통신사 투넘버 앱 · 문자함 |
| ☐ | 해외 결제 되는 **본인 명의** 카드 | 지갑 — 구글 $25 · 애플 $99 |
| ☐ | 은행 계좌 · 영문 은행 이름 · SWIFT 코드 | 은행 앱(외화 받는 계좌 안내) |

순서 이유: AdMob에서 만드는 **결제 프로필**(Google payments profile)을 Play Console이 같이 써요. 그래서 AdMob에서 처음부터 D-U-N-S 메일 글자 그대로 넣어 두면 Play Console에서 막히지 않아요.

## A. AdMob (약 20분)
### A1. 가입
1. 크롬에서 hello@ 로그인 → **myaccount.google.com > 보안(Security) > 2단계 인증(2-Step Verification)**이 '사용'인지 봐요.
2. **admob.google.com** → **시작하기(Get started)**
3. **국가 또는 지역** = 대한민국 · **시간대** = (GMT+09:00) 서울 · **결제 통화** = KRW(대한민국 원) → 약관 동의 → **AdMob 계정 만들기(Create AdMob account)**
   - ⚠ 시간대 · 통화는 나중에 바꾸기 어려워요.
4. 이메일 수신 고르기 화면이 나오면 '도움말 · 실적 제안'은 꺼도 돼요. '계정 · 지급 관련'은 켜 둬요.
- ✅ AdMob **홈(Home)** 화면이 열려요.
- 🔒 이 단계 값은 공개 안 돼요.

### A2. 지급 정보 · 결제 프로필
1. 왼쪽 **지급(Payments)** → **설정 관리(Manage settings)** 또는 **결제 정보 추가(Add payment info)** [화면 확인]
2. **계정 유형** = **비즈니스(Business)** (⚠ 나중에 바꿀 수 없어요. Play 조직 계정과 맞추려고 비즈니스로 해요)
3. `[ 직접 ]` 이름(상호) · 주소 → **D-U-N-S 발급 메일의 영문 상호 · 영문 주소를 글자까지 그대로** 붙여 넣기
4. `[ 직접 ]` 연락처 이름 · 전화 → 사업자등록증의 대표자 이름 · 투넘버
5. **제출(Submit)**
- ✅ 지급 화면에 결제 프로필 이름이 보여요.
- 🔒 공개 안 돼요.
- 지급 받을 은행 계좌(지급 수단)는 지금 넣지 않아도 돼요. 수입이 **$10**가 되면 AdMob이 '지급 수단 추가'와 **본인 인증**을 요청해요. 그때 **PIN 우편**이 결제 프로필 주소로 와요(2~3주, 4개월 안에 입력).

### A3. 세금 정보 (미국 세금 · W-8BEN)
1. **지급(Payments)** → **설정 관리(Manage settings)** → '결제 프로필' 칸의 **미국 세금 정보(United States tax info)** 옆 연필 → **세금 정보 관리(Manage tax info)**
2. 질문에 답해요: **미국인이 아님** → **개인(Individual)** (1인 개인사업자는 법인이 아니라 '개인'이에요) → 서식 **W-8BEN** [화면 확인 — 화면이 고른 서식을 따라요]
3. `[ 직접 ]` 이름 · 주소 = A2와 같은 글자 · 외국 납세자 번호(TIN) = 화면 안내가 요구하는 번호(사업자등록증 또는 신분증) · 조세조약 나라 = 대한민국
4. 전자서명 → **제출(Submit)**
- ✅ '세금 정보 승인됨'(또는 제출됨)이 보여요.
- 🔒 공개 안 돼요. 이 세금 정보는 결제 프로필에 붙어서, Play Console에서 같은 결제 프로필을 쓰면 다시 안 내도 될 수 있어요(B3에서 확인).

### A4. 게시자 ID 찾기 → 탭 3에 한 줄
1. 왼쪽 **설정(Settings)** → **계정 정보(Account information)**
2. **게시자 ID(Publisher ID)** = `pub-` 으로 시작하는 숫자
- ✅ `pub-0000000000000000` 꼴의 줄이 보여요.
- 📨 **탭 3에 그대로 한 줄로 보내 주세요.** 비밀 값이 아니에요. 사이트에 `app-ads.txt`를 올릴 때 써요(스토어가 광고 앱을 확인하는 파일).
- 🌐 이 ID는 `app-ads.txt`로 원래 공개되는 값이에요.

### A5. 광고 단위 — ⏸ 지금 안 함
- 앱이 Play Console · App Store Connect에 생긴 **뒤**(10/29 `스토어_등록_순서표_1029.md` 끝난 뒤) 해요. 스토어 앱과 연결해서 만들어야 해서요.
- 만들 목록: 탭 4 `~/shallwedog-server/docs/꾸미기_가격안.md` **5절 표** (앱마다 6개 × 2 = 12개).

## B. Play Console 조직 계정 ($25, 약 40분 + 확인 기다림)
### B1. 가입 · 계정 종류
1. **play.google.com/console/signup** (hello@ 로그인 상태) → 계정 종류 **조직(Organization)** → **조직 계정 만들기** [화면 확인]
2. **결제 프로필(Payments profile)** 고르기 → A2에서 만든 프로필이 보이면 그것 → `[ 직접 ]` **D-U-N-S 번호**(D-U-N-S 발급 메일)
   - 넣으면 조직 이름 · 주소가 D&B 기록에서 채워져요. **결제 프로필 이름 · 주소가 D&B와 글자까지 같아야** 해요.
   - ⛔ '주소가 일치하지 않음'이 나오면: 공식 안내대로 **새 결제 프로필 만들기**를 눌러 D&B 값으로 다시 만들어요. 그래도 안 되면 D&B 기록을 먼저 고치고(반영까지 최대 5영업일) 다시 해요.
- ✅ 조직 이름 · 주소가 D-U-N-S 메일과 같은 글자로 보여요.

### B2. 내 정보 (About you)
| 칸 | `[ 직접 ]` 어디 있는 값인지 | 공개 |
|---|---|---|
| 개발자 이름(Developer name) | `Shall We Dog` (법적 이름과 달라도 돼요) | 🌐 |
| 조직 유형 · 규모 | 회사 · 1명 | 🔒 |
| 조직 전화번호(Organization phone) | 투넘버 (사람들이 사업자를 찾을 때 나오는 번호) | 🔒 (스토어엔 안 나옴) |
| 조직 웹사이트(Organization website) | https://shallwedog.com | 🔒 |
| **연락처 정보** — 연락처 이름 · 연락처 이메일 · 연락처 전화 (Google이 나에게 연락) | 대표자 이름 · hello@ · 투넘버 | 🔒 |
| **사용자 연락처** — 개발자 이메일 · **개발자 전화번호** | hello@shallwedog.com · **투넘버** | 🌐 전 세계 |
| 주소 (D-U-N-S에서 옴) | 고칠 수 없어요 | 🌐 **수익을 내는 계정은 전체 주소가 공개돼요** |
- 이메일 · 전화 4칸은 각각 **일회용 코드(OTP)**로 인증해요. 투넘버 문자가 오는지 미리 확인해요.
- ✅ 네 칸 모두 '인증됨'.

### B3. 등록비 $25 · 본인 확인
1. **등록 수수료 결제** → 본인 카드 $25
2. **신원 확인(Verify identity)** → 대표자 **신분증** + **주소 증명**(정부 서류 · 공과금 고지서 · 은행 거래 내역 등 — 기간이 지나지 않은 것) 사진 올리기
   - 흑백 복사본은 원본이 흑백일 때만 돼요.
- ✅ '확인 중'(인증 진행 중) 표시 → 끝나면 메일로 '인증 완료'
- 🔒 신분증 · 서류는 공개 안 돼요.

### B4. 한국 사업자 정보 (계정 세부정보 > 업체 문의 연락처 세부정보)
| 칸 | `[ 직접 ]` 어디 있는 값인지 | 공개 |
|---|---|---|
| 연락처 주소 · 문의 전화번호 | 사업자등록증 주소 · 투넘버 | 🇰🇷 |
| 사업자 등록 번호 | 사업자등록증 | 🇰🇷 앱 설명 아래 |
| **통신판매 신고 번호 · 신고 기관(시 · 군 · 구청)** | 통신판매업 신고증 | 🇰🇷 |
- ⚠ **막히기 쉬운 곳:** 구글은 **유료 앱 · 앱 안 결제를 파는 한국 업체**에 통신판매 신고 번호를 요구해요. 지금 사이트에는 이 번호가 없어요(필요한지 확인 중이었음). 아래 '막히기 쉬운 곳 ③'을 봐요.

### B5. 결제 프로필 · 미국 세금
1. **설정(Settings)** → **결제 프로필(Payments profile)** → **설정 관리** → **미국 세금 정보** 확인
   - A3에서 같은 결제 프로필에 W-8BEN을 냈으면 '승인됨'으로 보여요. 없으면 A3과 같은 순서로 **개인 · W-8BEN** 내기.
2. **지급 받는 방법** → **결제 수단 추가** → `[ 직접 ]` 은행 계좌(은행 앱) → **인증**
- ✅ 결제 수단 '인증됨' (인증에 최대 5일)
- 🔒 공개 안 돼요.

### B6. EU 트레이더 신고 (구글)
- 구글 공식 도움말에서 **EU 디지털서비스법(DSA) 트레이더 신고 칸을 따로 찾지 못했어요**(10/28).
- 구글은 수익을 내는 조직 계정이면 **전 세계에** 이름 · 전체 주소 · 개발자 이메일 · 개발자 전화를 이미 공개해요(B2 표). 그래서 EU에서 더 드러나는 값은 없어요.
- 화면에 '판매자(트레이더) 상태' 질문이 나오면: **트레이더(Trader) = 예**(광고 · 앱 안 결제로 돈을 벌어서) → 값은 B2와 같은 것.

### B7. 라이선스 테스트 (시험 결제를 돈 안 내고)
1. Play Console 첫 화면(앱 목록)에서 왼쪽 **설정(Settings)** → **라이선스 테스트(License testing)**
2. `[ 직접 ]` 시험용 지메일 주소 넣기(이메일 목록) → **변경사항 저장(Save changes)**
- ✅ 목록에 지메일이 보여요. 이 계정은 앱 안 상품을 사도 돈이 안 나가요.
- 🔒 공개 안 돼요. hello@ 계정은 원래 테스터로 쳐요.
- 실제 시험 결제는 앱이 내부 테스트로 올라가고 **상품이 게시된 뒤**에 돼요(탭 4 · 탭 1).

## C. Apple Developer 개인 등록 ($99, 약 30분 + 승인 기다림)
⚠ 애플은 **1인 개인사업자는 개인(Individual)**으로 등록해야 해요. 스토어 '판매자'에 **본인 법적 이름**이 나와요(상호 아님). 🌐

### C1. Apple ID 2단계
1. 아이폰 **설정 > [내 이름] > 로그인 및 보안(Sign-In & Security) > 이중 인증(Two-Factor Authentication)** = 켬
2. Apple ID는 hello@shallwedog.com 또는 본인 Apple ID — **하나로 정해서 계속 그걸로** (나중에 옮기기 어려워요)
- ✅ '이중 인증: 켬'

### C2. 개인 등록 · $99
1. 아이폰 **Apple Developer 앱** → **계정(Account)** → **지금 등록(Enroll Now)** (웹은 developer.apple.com/programs/enroll)
2. 종류 **개인 / 개인 사업자(Individual / Sole Proprietor)**
3. `[ 직접 ]` **법적 이름**(신분증 이름 그대로 — 별명 · 상호 X) · 주소 · 전화
4. 프로그램 계약 동의 → **본인 카드**로 $99(원화로 보일 수 있어요)
   - 본인 카드가 아니면 사진 신분증을 따로 요청받고 그동안 멈춰요.
- ✅ 확인 메일(등록 ID가 적힘) → 승인되면 '멤버십 확인' 메일
- ⏳ 공식 안내: **24시간 안에 확인 메일이 없으면** Apple Developer 지원팀에 등록 ID로 문의해요.

### C3. 계약 · 은행 · 세금 (App Store Connect)
1. **appstoreconnect.apple.com** → 위 **비즈니스(Business)** → **계약(Agreements)** 탭
2. **유료 앱(Paid Apps)** 계약 → 보기 · **동의**
3. **은행 계좌 추가** → `[ 직접 ]` 은행 앱의 계좌 · SWIFT
4. **세금 양식(Tax Forms)** → **세금 정보 추가** → 미국 양식 **W-8BEN**(개인) → 한국 양식이 나오면 `[ 직접 ]` 사업자등록번호(사업자등록증)
   - ⚠ **제출하면 화면에서 못 고쳐요.** 이름 · 주소를 C2와 같은 글자로 넣었는지 보고 **제출**.
- ✅ 계약 상태 **활성(Active)**
- 🔒 은행 · 세금은 공개 안 돼요.

### C4. 한국법 표시 (비즈니스 > 계약 > 규정 준수 > 한국법)
- 개인은 **이메일 · 사업자등록번호**를 넣어요(C3에서 낸 한국 세금 양식에서 자동으로 옴).
- 🇰🇷 한국 App Store 상품 페이지에 공개돼요.
- ✅ '한국법' 옆 완료 표시

### C5. EU 트레이더 신고 (비즈니스 > 계약 > 규정 준수 > 디지털 서비스법 > 규정 준수 요구 사항 완료)
- **거래자 계정입니다(This is a trader account)**를 골라요. 광고 · 앱 안 결제로 돈을 벌면 트레이더예요.
- 애플 공식 문서: 개인은 **주소 또는 사서함 · 전화 · 이메일**을 넣고, 이것이 **EU 27개국 App Store 상품 페이지에 공개**돼요. 🇪🇺
  - 이메일 · 전화: 코드로 인증(전화가 코드를 못 받으면 '수동 확인 요청')
  - 주소: 상호 · 주소가 보이는 최신 서류(사업자등록증 등) 올리기. 사서함을 쓰면 그 사서함 영수증 · 청구서도 올려야 해요.
- **고를 것 (결정은 사용자)**
