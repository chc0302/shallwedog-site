# 커스텀 주문서 디자인 시안 2개 (탭 3, 11/8 — 사용자가 고르면 탭 1이 구현)

게임의 귀여운 톤과 다르게, 주문서만 **진지하고 차분한 톤**으로. 두 시안 모두 칸 순서 · 문구는 지금 앱(`AppUiController.Order.cs` · `strings.txt`)과 같아요.

| | 시안 A — 종이 주문서 | 시안 B — 흰 카드 |
|---|---|---|
| 그림 | `시안A_종이주문서_첫화면.png` · `_전체.png` | `시안B_흰카드_첫화면.png` · `_전체.png` |
| 느낌 | 크림색 종이에 쓰는 주문서 · 번호 01~07 · 밑줄 칸 | 흰 카드를 한 장씩 · 둥근 칸 · 조용한 앱 설정 화면 느낌 |
| 바탕 · 글씨 | 바탕 `#F7F3EA` · 글씨 `#2B2A27` · 보조 `#8A8276` | 바탕 `#F5F5F2` · 카드 `#FFFFFF` · 글씨 `#1F2328` · 보조 `#8B9094` |
| 선 | 칸 사이 `#D8D0C0` 1px · 입력은 밑줄만 | 카드 테두리 `#E4E4E0` 1px · 둥글기 12 / 칸 8 |
| 강조 | 먹색 하나(`#2B2A27`) — 고른 칸은 먹색 채움 | 짙은 초록 하나(`#2F4A3F`) — 고른 칸은 초록 테두리 |
| 제목 글씨 | 명조(AppleMyungjo) · 본문은 고딕 가늘게 | 고딕 가늘게(300) |
| 버튼 | 각진 먹색 · 글자 간격 넓게 | 둥근 짙은 초록 |

- 칸: 01 이 아이는 어떤 아이인가요?(필수, 맨 위) · 02 이름 · 03 견종(+믹스) · 04 체형 · 05 지금 털 · 06 특징 + 한 줄 메모 · 07 사진 2장(얼굴 정면 · 몸 전체) · 주문 보내기
- 맨 위 소개 줄: '보통 **2~3일 안에** 받아보실 수 있어요'
- 앱에서는 사진이 주문서 앞 단계예요. 시안은 한 화면에 다 보이게 맨 아래에 모았어요 — 구현할 때 지금 순서를 그대로 둬도 돼요.
- 그림 속 사진은 사이트의 `assets/img/custom-real.webp`, 이름 '콩이'는 예시예요.
