# 통신판매업 신고 순서표 + 해외에서 따로 할 일 (탭 3, 10/28 17차)

사용자 결정(10/28): **출시 전에 신고해요.** 일반과세자이고 올해 판매가 100건을 넘어서 면제(간이과세자 · 직전 해 50회 미만)에 해당하지 않아요. 구글 Play는 앱 안 결제를 파는 한국 업체에 통신판매 신고 번호 · 신고 기관을 요구해요(`개발자계정_만들기_순서표.md` B4).
- 신고 하나로 **스마트스토어(전자상거래 소매)와 게임 앱 안 결제를 함께** 해요. 통신판매업 신고는 사업자마다 하나예요(판매처마다 따로 하지 않음).
- 이 종이에 상호 · 주소 · 등록번호 · 신고번호 값은 쓰지 않아요. `[ 직접 ]` = 화면에 바로 넣어요.
- ✅ = 이게 보이면 성공. [화면 확인] = 화면 이름이 조금 다를 수 있어요.

## 1. 구매안전서비스 확인증 (먼저 — 없으면 정부24 신청이 중간에 멈춰요)
| 판매처 | 첨부할 것 | 어디서 |
|---|---|---|
| 스마트스토어 | **구매안전서비스 이용확인증** | 스마트스토어센터 → **판매자 정보** → **판매자 정보** 화면의 '구매안전서비스 이용확인증' **출력/다운로드** [화면 확인] |
| 게임 앱(애플 · 구글 결제) | **구매안전서비스 비적용 대상 확인서**(소명자료) | 정부24 신청 화면 첨부 칸 또는 구청 양식 [화면 확인]. 아래 이유를 적어요 |
- 관할 구청 안내: 오픈마켓(네이버 등)을 쓰면 그 오픈마켓에서 확인증을 받고, **두 가지 판매 방식을 함께 쓰면 2장 모두** 내요. 적용 대상이 아니면 '구매안전서비스 비적용 대상 확인서'를 내요.
- 앱 안 결제가 비적용인 이유(확인서에 쓸 말): `앱 안 상품은 애플(App Store) · 구글(Google Play)이 결제를 처리하고, 신용카드 등으로 결제되며, 배송이 없는 디지털 콘텐츠예요.` — 구매안전서비스 의무의 예외(신용카드 결제 · 배송이 없는 재화)는 2차 자료로 확인했어요. ☐ 구청이 '스마트스토어 확인증 1장이면 된다'고 하면 확인서는 빼요.
- ✅ 확인증 PDF(또는 캡처) 1장 + 확인서 1장이 폴더에 있어요.

## 2. 정부24 신고 (약 20분)
1. **정부24** 로그인 — **대표자 본인 명의**(공동인증서 · 간편인증)
2. 위 검색창에 `통신판매업 신고` → **통신판매업 신고** 민원 → **신청**
3. 칸 채우기
   | 칸 | `[ 직접 ]` 어디 있는 값인지 · 고를 것 |
   |---|---|
   | 신고인 · 상호 · 사업자등록번호 | 사업자등록증 (로그인하면 일부 자동) |
   | 사업장 소재지 · 전화 | 사업자등록증 주소 · 투넘버 |
   | 전자우편 | `hello@shallwedog.com` |
   | 인터넷 도메인 이름 | 스마트스토어 주소(판매자센터 '스토어 URL') + `shallwedog.com` (칸이 하나면 쉼표로 이어서) |
   | 호스트서버 소재지 | 스마트스토어 = 네이버, `shallwedog.com` = 미국(GitHub Pages) [화면 확인 — 고르는 칸이면 '국내'를 먼저 넣고 나머지는 비고] |
   | **판매 방식** | **인터넷** (앱 마켓 판매도 인터넷이에요) |
   | **취급 품목** | 여러 개를 고를 수 있으면: 스마트스토어 품목 칸 + **교육/도서/완구/오락** 쪽 칸(게임). 하나만 고르면: **종합몰** [화면 확인 — 목록 이름은 화면 그대로] |
   | 첨부 | 1절의 확인증(+ 확인서) |
   | 받는 방법 | **온라인 발급**(정부24에서 출력)이 있으면 그것, 없으면 방문 수령 |
4. **제출(민원 신청하기)**
- ✅ '신청 완료' + 접수번호. **My GOV > 나의 신청내역**에 '처리 중'
- ⚠ 2차 자료에 '해외에 둔 도메인이면 온라인 접수가 안 되고 방문'이라는 말이 있어요. 정부24가 받지 않으면 사업자등록증 · 확인증 · 신분증을 들고 관할 구청 지역경제과로 가요.

- 온라인: 정부24 **My GOV > 나의 신청내역 > 서비스 신청내역** → 처리 완료 줄 → **신고증 출력**(PDF로 저장)

- ✅ 신고증 PDF에 **신고번호**(제 20XX-서울○○-XXXX호 꼴)와 **신고 기관**(○○구청)이 보여요.

## 6. "해외 것들도 다 해야 되는지" — 나라별로 따로 할 일

**내가 정한 것 (6절)**
- ⚠ 줄(스위스 · 콜롬비아 · 페루 · 탄자니아 · 짐바브웨의 **구글**, 브라질의 **애플 · 구글**, 중국 본토의 **애플**)은 **출시 국가에서 빼는 안**을 기본으로 적어요. 빼면 우리가 그 나라 세금 등록을 따로 할 일이 없어요. 넣을지는 사용자가 정해요(빼도 나중에 켤 수 있어요).
