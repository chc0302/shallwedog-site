## A. 구글 Play Console — 앱 콘텐츠

**주소:** https://play.google.com/console → **Shall We Dog?** 앱 → 왼쪽 메뉴 **모니터링 및 개선 > 정책 및 프로그램 > 앱 콘텐츠** [화면 확인]
각 줄의 **시작** (또는 **관리**) → 답 → **저장**.

### A1. 개인정보처리방침
- 칸: `https://shallwedog.com/en/privacy/` 📋 → 저장

### A2. 앱 액세스 권한
- **모든 기능을 특별한 액세스 권한 없이 사용할 수 있음** → 저장
- 심사관이 따로 요청할 때만: `스토어_붙여넣기표_1103.md` B3의 '앱 액세스 권한 메모'(영어) 붙이기

### A3. 광고
- **예, 앱에 광고가 포함되어 있습니다** → 저장

### A4. 콘텐츠 등급 (IARC 설문)
1. **설문지 시작** → 이메일 `hello@shallwedog.com` 📋 → 카테고리 **게임**
2. 답:

| 질문 | 답 |
|---|---|
| 폭력 · 공포 · 성적 내용 · 욕설 · 술 · 담배 · 약물 | 모두 **아니요** |
| 도박 · 시뮬레이션 도박 | **아니요** |
| 돈 내고 사는 랜덤 아이템(루트박스) | **아니요** |
| 사용자끼리 대화 · 콘텐츠 공유 | **아니요** |
| 위치를 다른 사용자와 공유 | **아니요** |
| 디지털 상품 구매 | **예** |
| 제한 없는 인터넷 접속 · 웹 브라우저 | **아니요** |

3. **저장 → 다음 → 등급 제출**. 예상: 전체 이용가 쪽(나라마다 다름) 그대로 둠.

### A5. 타겟층 및 콘텐츠 (타깃 연령)
| 질문 | 답 |
|---|---|
| 타깃 연령 | **13~15세 · 16~17세 · 18세 이상** 체크 (13세 미만은 모두 비움) |
| 어린이의 관심을 끌 수 있나요? | **아니요** |
→ 다음 → 저장

### A6. 광고 ID
- **예** → 목적 **광고 또는 마케팅 · 분석** → 저장

### A7. 데이터 보안
**시작** → 공통 질문:

| 질문 | 답 |
|---|---|
| 필수 사용자 데이터 유형을 수집하거나 공유하나요? | **예** |
| 모든 사용자 데이터는 전송 중에 암호화되나요? | **예** |
| 데이터 삭제를 요청할 수 있는 방법을 제공하나요? | **예** |
| 계정 만들기 방법 | **OAuth** (0-6 안 끝났으면 **앱에서 계정을 만들 수 없음**) |
| 계정 삭제 URL | `https://shallwedog.com/en/delete/` 📋 |
| 독립 보안 검토 | 체크 안 함 |

데이터 유형 — 아래만 체크. **'일시적으로만 처리'는 모두 아니요.** '공유'는 **광고(AdMob)가 가져가는 것만 예**예요(Firebase · RevenueCat 등 처리 회사로 보내는 건 공유 아님).

| 유형 | 수집 | 공유 | 필수/선택 | 목적 |
|---|---|---|---|---|
| 개인 정보 > 사용자 ID | 예 | 아니요 | 선택 | 앱 기능, 계정 관리, 사기 방지 · 보안 · 규정 준수 |
| 개인 정보 > 이름 | **체크 안 함** | | | |
| 금융 정보 > 구매 내역 | 예 | 아니요 | 선택 | 앱 기능 |
| 사진 및 동영상 > 사진 | 예 | 아니요 | 선택 | 앱 기능 |
| 앱 활동 > 앱 상호작용 | 예 | **예** | 필수 | 분석, 광고 또는 마케팅 |
| 앱 활동 > 기타 사용자 생성 콘텐츠 | 예 | 아니요 | 선택 | 앱 기능 |
| 앱 활동 > 기타 작업 | 예 | 아니요 | 선택 | 앱 기능 |
| 앱 정보 및 성능 > 비정상 종료 로그 | 예 | 아니요 | 필수 | 분석 |
| 앱 정보 및 성능 > 진단 | 예 | **예** | 필수 | 분석, 광고 또는 마케팅 |
| 기기 또는 기타 ID | 예 | **예** | 필수 | 광고 또는 마케팅, 분석, 앱 기능 |
| 위치 > 대략적인 위치 | 예 | **예** | 필수 | 광고 또는 마케팅 |

→ **다음 → 미리보기 확인 → 저장.** 제출은 0절(0-6)까지 끝난 뒤.

## B. 애플 App Store Connect — 앱 개인정보 보호 (개인정보 라벨)

**주소:** https://appstoreconnect.apple.com/apps → **Shall We Dog?** → 왼쪽 **일반 > 앱 개인정보 보호 (App Privacy)**

1. **개인정보 처리방침 URL** 옆 **편집** → `https://shallwedog.com/en/privacy/` 📋 → 저장
2. **시작하기** → "이 앱에서 데이터를 수집합니까?" **예** → 아래 유형만 체크 → **저장**
3. 유형마다 **설정** → 사용자와 연결 · 추적 · 목적 고르기. **추적(Tracking)은 모두 아니요.**

| 데이터 유형 | 사용자와 연결 | 추적 | 목적 |
|---|---|---|---|
| 식별자 > 사용자 ID | 예 | 아니요 | 앱 기능 |
| 식별자 > 기기 ID | 예 | 아니요 | 제3자 광고, 분석, 앱 기능 |
| 구입 항목 > 구입 내역 | 예 | 아니요 | 앱 기능 |
| 사용자 콘텐츠 > 사진 또는 비디오 | 예 | 아니요 | 앱 기능 |
| 사용자 콘텐츠 > 게임 플레이 콘텐츠 | 예 | 아니요 | 앱 기능 |
| 사용자 콘텐츠 > 기타 사용자 콘텐츠 | 예 | 아니요 | 앱 기능 |
| 사용 데이터 > 제품 상호작용 | 아니요 | 아니요 | 분석, 제3자 광고 |
| 사용 데이터 > 광고 데이터 | 아니요 | 아니요 | 제3자 광고 |
| 위치 > 대략적인 위치 | 아니요 | 아니요 | 제3자 광고 |
| 진단 > 충돌 데이터 | 아니요 | 아니요 | 앱 기능, 분석 |
| 진단 > 기타 진단 데이터 | 아니요 | 아니요 | 앱 기능, 분석 |

- 체크하지 않는 것: 연락처 정보 · 건강 · 금융 정보 · 정확한 위치 · 연락처 목록 · 검색 · 브라우징 기록 · 민감한 정보 · **진단 > 성능 데이터**.
4. 오른쪽 위 **게시(Publish)** 는 0절이 끝난 뒤(제출 표 1절 그대로).

## C. 애플 App Store Connect — 연령 등급

**주소:** 같은 앱 → 왼쪽 **일반 > 앱 정보 (App Information)** → **연령 등급** 옆 **설정 (Set Up Age Ratings)** 또는 **편집**

| 묶음 > 질문 | 답 |
|---|---|
| 앱 내 통제 > 보호자 통제 | 아니요 |
| 앱 내 통제 > 연령 확인 | 아니요 |
| 기능 > 제한 없는 웹 접속 | 아니요 |
| 기능 > 사용자 생성 콘텐츠 | 아니요 |
| 기능 > 소셜 미디어 | 아니요 |
| 기능 > 메시지 및 채팅 | 아니요 |
| 기능 > 광고 | **예** |
| 성숙한 주제 (욕설 · 공포 · 술 · 담배 · 약물) | 모두 없음 |
| 의료 또는 건강 | 모두 없음 |
| 성적 내용 · 노출 | 모두 없음 |
| 폭력 (만화 · 사실적 · 잔혹 · 총 · 무기) | 모두 없음 |
| 확률형 > 도박 | 아니요 |
| 확률형 > 시뮬레이션 도박 · 대회 | 없음 |
| 확률형 > 루트박스 | 아니요 |
| 추가 정보 > 더 높은 연령 등급으로 재정의 | **13+** |
| 어린이용 (Made for Kids) | 고르지 않음 |
| 대한민국 등급 | **12세 이상** [화면 확인 — '전체 이용가'가 자동으로 나오면 그대로] |
→ **저장**. ✅ 앱 정보 페이지 연령 등급 칸에 **13+**.
