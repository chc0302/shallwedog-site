# 개발자 계정 만들기 순서표 — AdMob → Play Console → Apple (탭 3, 10/28 15차 · 17차 · 18차 고침)

오늘 위에서부터 차례로 해요. 모두 **hello@shallwedog.com 구글 계정**(2단계 켬)으로 시작해요. Firebase는 탭 4 `계정_생긴_날_순서표.md`대로 따로 해요.
- **굵은 글씨** = 누를 곳. 메뉴 이름은 한국어 화면 그대로이고, 괄호 안은 영어 화면 이름이에요.
- ✅ = 이게 보이면 성공이에요.
- 표시: 🌐 = 스토어에 공개돼요 · 🇰🇷 = 한국 사용자에게만 공개 · 🇪🇺 = EU 스토어에 공개 · 🔒 = 공개 안 됨(회사 · 스토어만 봄)
- `[ 직접 ]` 칸은 이 종이에 쓰지 않고 화면에 바로 넣어요. 옆에 그 값이 **어디 있는지**만 적었어요.
- 화면이 바뀌는 일이 잦아서 [화면 확인]이 붙은 곳은 비슷한 이름을 찾아 주세요.

## 0. 시작 전에 옆에 펴 둘 것

## A. AdMob (약 20분)
⚠ **먼저 두 가지 (10/28 18차)**
1. **개인 구글 아이디에 옛 AdMob 계정이 있으면 해지하고, hello@로 새로 가입해요.** AdMob 정책은 한 사람이 계정을 여러 개 가지면 하나나 둘 다 닫아요(사용자가 10/28 실제로 겪음). 옛 계정: admob.google.com(개인 아이디) → **설정(Settings) > 계정 정보(Account information) > 계정 해지(Close account)** [화면 확인].
2. **개인 구글 아이디와 섞이지 않게:** 사파리 · 크롬 어느 쪽이든 괜찮아요. **hello@만 로그인된 창**(사파리 프로필 또는 크롬 프로필 하나를 hello@ 전용으로)에서 AdMob · Play Console · Firebase를 해요. **단계마다 오른쪽 위 계정 동그라미가 hello@인지** 확인해요.
### A1. 가입
1. 크롬에서 hello@ 로그인 → **myaccount.google.com > 보안(Security) > 2단계 인증(2-Step Verification)**이 '사용'인지 봐요.
2. **admob.google.com** → **시작하기(Get started)**
3. **국가 또는 지역** = 대한민국 · **시간대** = (GMT+09:00) 서울 · **결제 통화** = KRW(대한민국 원) → 약관 동의 → **AdMob 계정 만들기(Create AdMob account)**
   - ⚠ 시간대 · 통화는 나중에 바꾸기 어려워요.
4. 이메일 수신 고르기 화면이 나오면 '도움말 · 실적 제안'은 꺼도 돼요. '계정 · 지급 관련'은 켜 둬요.
- ✅ AdMob **홈(Home)** 화면이 열려요.
- 🔒 이 단계 값은 공개 안 돼요.

### A2. 지급 정보 · 결제 프로필
1. 왼쪽 **지급(Payments)** → **설정 관리(Manage settings)** 또는 **결제 정보 추가(Add payment info)** [화면 확인]
2. **계정 유형** = **비즈니스(Business)** (⚠ 나중에 바꿀 수 없어요. Play 조직 계정과 맞추려고 비즈니스로 해요)
3. `[ 직접 ]` 이름(상호) · 주소 → **D-U-N-S 발급 메일의 영문 상호 · 영문 주소를 글자까지 그대로** 붙여 넣기
4. `[ 직접 ]` 연락처 이름 · 전화 → 사업자등록증의 대표자 이름 · 투넘버
5. **제출(Submit)**
- ✅ 지급 화면에 결제 프로필 이름이 보여요.
- 🔒 공개 안 돼요.
- 지급 받을 은행 계좌(지급 수단)는 지금 넣지 않아도 돼요. 수입이 **$10**가 되면 AdMob이 '지급 수단 추가'와 **본인 인증**을 요청해요. 그때 **PIN 우편**이 결제 프로필 주소로 와요(2~3주, 4개월 안에 입력).

### A3. 세금 정보 (미국 세금 · W-8BEN)
1. **지급(Payments)** → **설정 관리(Manage settings)** → '결제 프로필' 칸의 **미국 세금 정보(United States tax info)** 옆 연필 → **세금 정보 관리(Manage tax info)**
2. 질문에 답해요: **미국인이 아님** → **개인(Individual)** (1인 개인사업자는 법인이 아니라 '개인'이에요) → 서식 **W-8BEN** [화면 확인 — 화면이 고른 서식을 따라요]
3. `[ 직접 ]` 칸 채우기 — **W-8BEN은 개인용 서식이에요**(1번 칸 = 'Name of individual who is the beneficial owner')
   - **이름 = 대표자 본인 영문 이름(여권 철자 그대로)** — 상호 X
   - 화면에 **'사업체 이름(Business name)'** 칸이 따로 있으면 그 칸에만 상호(D-U-N-S 메일의 영문 상호)
   - 주소 = A2와 같은 글자(D-U-N-S 메일의 영문 주소)
   - 외국 납세자 번호(TIN) = 화면 안내가 요구하는 번호 · 조세조약 나라 = 대한민국
4. 전자서명 → **제출(Submit)**
- ✅ '세금 정보 승인됨'(또는 제출됨)이 보여요.
- 🔒 공개 안 돼요. 이 세금 정보는 결제 프로필에 붙어서, Play Console에서 같은 결제 프로필을 쓰면 다시 안 내도 될 수 있어요(B3에서 확인).

### A4. 게시자 ID 찾기 → 탭 3에 한 줄
1. 왼쪽 **설정(Settings)** → **계정 정보(Account information)**
2. **게시자 ID(Publisher ID)** = `pub-` 으로 시작하는 숫자
- ✅ `pub-0000000000000000` 꼴의 줄이 보여요.
- 📨 **탭 3에 그대로 한 줄로 보내 주세요.** 비밀 값이 아니에요. 사이트에 `app-ads.txt`를 올릴 때 써요(스토어가 광고 앱을 확인하는 파일).
- 🌐 이 ID는 `app-ads.txt`로 원래 공개되는 값이에요.

### A5. 광고 단위 — ⏸ 지금 안 함
- 앱이 Play Console · App Store Connect에 생긴 **뒤**(10/29 `스토어_등록_순서표_1029.md` 끝난 뒤) 해요. 스토어 앱과 연결해서 만들어야 해서요.
- 만들 목록: 탭 4 `~/shallwedog-server/docs/꾸미기_가격안.md` **5절 표** (앱마다 6개 × 2 = 12개).

## B. Play Console 조직 계정 ($25, 약 40분 + 확인 기다림)
### B1. 가입 · 계정 종류
1. **play.google.com/console/signup** (hello@ 로그인 상태) → 계정 종류 **조직(Organization)** → **조직 계정 만들기** [화면 확인]
2. **결제 프로필(Payments profile)** 고르기 → A2에서 만든 프로필이 보이면 그것 → `[ 직접 ]` **D-U-N-S 번호**(D-U-N-S 발급 메일)
   - 넣으면 조직 이름 · 주소가 D&B 기록에서 채워져요. **결제 프로필 이름 · 주소가 D&B와 글자까지 같아야** 해요.
   - ⛔ '주소가 일치하지 않음'이 나오면: 공식 안내대로 **새 결제 프로필 만들기**를 눌러 D&B 값으로 다시 만들어요. 그래도 안 되면 D&B 기록을 먼저 고치고(반영까지 최대 5영업일) 다시 해요.
- ✅ 조직 이름 · 주소가 D-U-N-S 메일과 같은 글자로 보여요.

1. **등록 수수료 결제** → 본인 카드 $25
2. **신원 확인(Verify identity)** → 대표자 **신분증** + **주소 증명**(정부 서류 · 공과금 고지서 · 은행 거래 내역 등 — 기간이 지나지 않은 것) 사진 올리기
   - 흑백 복사본은 원본이 흑백일 때만 돼요.
- ✅ '확인 중'(인증 진행 중) 표시 → 끝나면 메일로 '인증 완료'
- 🔒 신분증 · 서류는 공개 안 돼요.

### B4. 한국 사업자 정보 (계정 세부정보 > 업체 문의 연락처 세부정보)

| 사업자 등록 번호 | 사업자등록증 | 🇰🇷 앱 설명 아래 |

- ⚠ 구글은 **유료 앱 · 앱 안 결제를 파는 한국 업체**에 통신판매 신고 번호를 요구해요. 사용자 결정(10/28 17차): **출시 전에 신고해요** → `통신판매업_신고_순서표.md`. 신고증이 나오기 전이면 이 두 칸만 비워 두고 다음 단계로 가요(신고증 5절에서 다시 와서 넣기).

1. **설정(Settings)** → **결제 프로필(Payments profile)** → **설정 관리** → **미국 세금 정보** 확인
   - A3에서 같은 결제 프로필에 W-8BEN을 냈으면 '승인됨'으로 보여요. 없으면 A3과 같은 순서 · **같은 이름 규칙**(이름 = 대표자 영문 이름 여권 철자, 상호는 '사업체 이름' 칸에만)으로 **개인 · W-8BEN** 내기.
2. **지급 받는 방법** → **결제 수단 추가** → `[ 직접 ]` 은행 계좌(은행 앱) → **인증**
- ✅ 결제 수단 '인증됨' (인증에 최대 5일)
- 🔒 공개 안 돼요.

### B6. EU 트레이더 신고 (구글)
- 구글 공식 도움말에서 **EU 디지털서비스법(DSA) 트레이더 신고 칸을 따로 찾지 못했어요**(10/28).
- 구글은 수익을 내는 조직 계정이면 **전 세계에** 이름 · 전체 주소 · 개발자 이메일 · 개발자 전화를 이미 공개해요(B2 표). 그래서 EU에서 더 드러나는 값은 없어요.
- 화면에 '판매자(트레이더) 상태' 질문이 나오면: **트레이더(Trader) = 예**(광고 · 앱 안 결제로 돈을 벌어서) → 값은 B2와 같은 것.

2. `[ 직접 ]` 시험용 지메일 주소 넣기(이메일 목록) → **변경사항 저장(Save changes)**
- ✅ 목록에 지메일이 보여요. 이 계정은 앱 안 상품을 사도 돈이 안 나가요.
- 🔒 공개 안 돼요. hello@ 계정은 원래 테스터로 쳐요.

⚠ 애플은 **1인 개인사업자는 개인(개인 / 개인 사업자)**으로 등록해야 해요. 스토어 '판매자'에 **본인 법적 이름(로마자)**이 나와요(상호 아님). 🌐
**한눈에 (애플 공식 문서 기준)**

| 주소 | 확인해요. **사서함 주소는 안 돼요**(등록용 — EU 트레이더 공개 주소와 다른 규칙) |
| 승인까지 | 공식 기간 안내는 없어요. **구입 뒤 24시간 안에 '멤버십 확인' 메일이 없으면** 등록 ID를 적어 문의해요 |
| 소규모 사업자(15%) | **유료 앱 계약(C3)이 '활성'이 된 날 바로** 신청해요. 15%는 승인된 회계 월이 끝나고 15일 뒤부터예요 |

### C1. 새 Apple ID (hello@shallwedog.com · 2단계 문자 = 투넘버)
1. 맥이나 PC 브라우저(사파리 hello@ 전용 프로필이면 좋음)에서 **account.apple.com** → **Apple 계정 생성**(Create Your Apple Account) [화면 확인]
2. `[ 직접 ]` 칸
   | 칸 | 넣을 것 | 공개 |
   |---|---|---|
   | 성 · 이름 | **여권의 영문 철자 그대로**(대문자 · 띄어쓰기까지). 별명 · 상호 X | 🌐 나중에 판매자 이름으로 |
   | 생년월일 · 나라 | 본인 · **대한민국** | 🔒 |
   | 이메일 | `hello@shallwedog.com` | 🔒 |
   | 전화번호 | **투넘버**(문자로 받기) | 🔒 |
3. hello@ 받은편지함(Zoho)에 온 **6자리 코드** → 입력 · 투넘버 문자 **6자리 코드** → 입력
- ✅ account.apple.com에 hello@로 로그인되고 **로그인 및 보안**에 '이중 인증: 켬' · 신뢰할 수 있는 전화번호 = 투넘버
- ⚠ 막히기 쉬운 곳
  - '이 이메일은 이미 사용 중' → 예전에 hello@로 만든 Apple ID가 있는 거예요. 새로 만들지 말고 **암호 재설정**으로 그 계정을 써요.
  - 투넘버 문자가 안 와요 → 30초 뒤 **코드 다시 보내기** → 그래도 안 되면 **전화로 받기** [화면 확인]. 투넘버 문자가 본 번호 문자함 · 투넘버 앱 중 어디로 오는지 먼저 봐 두세요.
  - '지금은 계정을 만들 수 없음' → 같은 기기 · 같은 번호로 하루에 여러 계정을 만들면 막힐 수 있어요(공식 기준 없음). 다음 날 다시 해요.
  - Zoho 스팸함에 코드 메일이 갈 수 있어요.

### C2. 개인 등록 (아이폰 Apple Developer 앱)
준비: Face ID · Touch ID 또는 암호가 켜진 아이폰, **iCloud에 로그인된 기기**(폰의 Apple ID는 개인 것 그대로 둬도 돼요), 최신 **Apple Developer** 앱(App Store), **여권**. ⚠ **등록을 끝낼 때까지 같은 아이폰**으로 해요.
1. **Apple Developer** 앱 → 아래 **계정** 탭 → **로그인** → **hello@shallwedog.com**(C1의 새 ID — 폰의 Apple ID와 달라도 돼요) → 투넘버 코드
2. **Apple Developer 계약** → **동의**
3. **지금 등록하기** → 혜택 · 요구 사항 보기 → **계속**
4. 개인정보: `[ 직접 ]` **이름 · 성 = C1과 같은 여권 영문 철자** · 전화 = 투넘버 · 주소 = **실제 사는 곳(사서함 X)**
   - 한국어 이름 칸이 따로 나오면 한글 법적 이름, 로마자 칸에는 여권 철자
5. **신분증으로 신원 확인** → 여권 사진면 촬영(밝은 곳 · 반사 없이 · 네 귀퉁이가 다 보이게)
6. 정보 확인 → **계속** → 법인 유형 **개인** → **Apple Developer Program 사용권 계약서** → **동의**
7. ⛔ **여기서 멈춤** — 구독 화면의 **원화 금액 · 매년 자동 갱신**을 확인해요. 결제는 폰 Apple ID(개인)에 등록된 카드로 나가요(공식: 등록 계정과 같을 필요 없음 · Apple 계정 잔액 · 기프트 카드는 못 씀).
8. **구독** → Face ID
- ✅ '등록 ID'가 적힌 확인 메일(hello@) → 승인되면 **멤버십 확인** 메일 · 앱 계정 탭에 'Apple Developer Program' 멤버십 표시
- 🌐 공개: 로마자 법적 이름(판매자). 🔒 나머지(여권 · 주소 · 전화 · 카드)는 공개 안 돼요.
- ⚠ 막히기 쉬운 곳
  - **이름 불일치**: Apple 계정 이름과 여권 영문 철자가 다르면 신원 확인이 거절될 수 있어요(개발자 포럼 사례). C1에서 여권 철자로 맞춘 이유예요.
  - **신원 확인 거절 · 다시 하기 버튼 없음** → 앱에서 다시 하지 말고 developer.apple.com/kr/contact 에 '등록' 문의(등록 ID 적기).
  - 신원 확인은 **한 Apple 계정에만** 묶여요(공식: 다른 Apple 계정으로 다시 확인할 수 없음). 예전에 개인 Apple ID로 신원 확인을 한 적이 있으면 hello@로는 막힐 수 있어요 → 그때는 지원팀 문의.
  - 신분증 사진을 내고 싶지 않으면 다른 확인 방법을 애플에 문의할 수 있어요(공식).
  - 웹으로 할 때: 본인 명의 신용카드(미화 결제 가능)가 아니면 사진 신분증 사본을 따로 요청받고 그동안 멈춰요.

### C3. 계약 · 은행 · 세금 (App Store Connect — 멤버십 승인 뒤)
1. **appstoreconnect.apple.com**(hello@) → 위 **비즈니스** → **계약** 탭
2. **유료 앱**(Paid Apps) 계약 → **보기** → **동의**
3. **은행 계좌 추가** → `[ 직접 ]` 은행 앱의 계좌 · SWIFT 코드
4. **세금 양식** → **세금 정보 추가** → 미국 양식 **W-8BEN**(개인)

   - ⚠ **제출하면 화면에서 못 고쳐요.** 여권 철자 · 주소를 한 번 더 보고 **제출**.
