# 구글 플레이 조직 계정 · 사이트 확인 파일 올리는 법

구글 공식 안내(2026-10 확인): 조직 계정의 누리집 확인은 **Google Search Console**로 해요.
흐름 = ① Search Console에 shallwedog.com 등록(이때 확인 파일을 받음) → ② Play Console '신원(Identity)' 화면에서 요청 → ③ 같은 구글 계정이면 자동 승인.
Search Console에서 속성 종류를 고를 때 **'URL 접두어'**를 고르세요('도메인'을 고르면 DNS TXT만 돼요). 확인 방법은 **HTML 파일**.

## 사용자가 할 일
1. Search Console 화면에서 확인 파일(예: `google1234abcd.html`)을 **다운로드**해요.
2. 다운로드한 파일을 Claude 입력창에 끌어다 놓거나, 파일 이름을 알려 줘요.
3. Claude가 "올렸어요" 하면 Search Console로 돌아가 **확인**을 누르고, Play Console 신원 화면에서 요청을 보내요.

## Claude가 할 일
- 파일을 내용 그대로, 이름 그대로 저장소 **맨 위 폴더**에 두고 `main`에 커밋 · 푸시.
  - 사이트가 `.nojekyll`이라 어떤 파일 이름이든 그대로 공개돼요. 1~2분 뒤 `https://shallwedog.com/<파일 이름>`을 열어 내용이 같은지 확인.
- 확인 문구를 **메타 태그**로 달라고 하면 `index.html`의 `<head>`에 그 한 줄만 넣어요.
- 파일은 확인이 끝나도 지우지 않아요. 지우면 확인이 풀릴 수 있어요.

## 하지 말 것
- 가비아 DNS의 MX · TXT(메일, Zoho)는 손대지 않아요. DNS 방식(TXT 추가)을 고르라고 하면 **HTML 파일 방식**을 고르세요.
  꼭 DNS로 해야 하면 기존 줄은 그대로 두고 **새 TXT 줄을 추가**만 해요.
