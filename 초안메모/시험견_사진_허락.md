# 시험견 사진 허락 — 카톡 문구 + 동의 항목 (탭 3, 10/28 14차)

출시 전에 지인 강아지 20마리 이상으로 커스텀 주문을 시험해요. 받는 사람이 부담 없게 짧게 썼어요. 회사 이름은 처리방침 5조와 같아요.

## 1. 처음 보내는 카톡 (복사해서 이름만 바꾸기)
```
○○야 안녕! 내가 만드는 강아지 게임(Shall We Dog?)에서 사진 2장으로 우리 집 강아지를 닮은 3D 강아지를 만들어 주는 기능을 시험하고 있어.
출시 전에 여러 강아지로 많이 만들어 봐야 해서, 혹시 ○○(강아지) 사진 2장 보내 줄 수 있어? 완성되면 결과 보여 줄게. 돈은 안 들어!

필요한 사진
1) 얼굴이 정면으로 보이는 사진
2) 서 있는 몸 전체가 나온 사진
(사람 얼굴은 안 나오게, 강아지 한 마리만)

괜찮으면 아래 동의 내용 한번 읽고 답 줘 🙏
```

## 2. 동의 내용 (카톡으로 이어서 보내기)
```
[사진 쓰는 곳 안내]
• 사진은 강아지 3D 만들기 시험에만 써.
• 만드는 과정에서 사진이 아래 해외 처리 회사로 가: OpenAI OpCo, LLC · Anthropic, PBC(이미지 처리, 미국), Google LLC(저장, 미국), Meshy LLC(3D 제작 — 사진이 아니라 사진으로 만든 그림만 가, 미국), Telegram(내가 결과를 확인하는 메신저).
• 강아지 이름은 저장하지 않고 '시험견 07' 같은 번호로만 기록해.
• 사진은 시험이 끝나면(결과 보여 준 날부터 14일 안에) 지워.
• 언제든 "지워 줘"라고 카톡이나 hello@shallwedog.com으로 말하면 바로 지우고 알려 줄게.

[골라 줘]
① 사진을 시험에 써도 돼 → 예 / 아니요
② 완성된 3D 강아지를 게임 소개 · 인스타에 '제작 예시'로 올려도 돼 (사진 원본은 안 올림) → 예 / 아니요
②는 안 해도 ①만으로 충분해!
```

## 3. 답이 오면 기록 (탭 3 · 사용자만 보는 표, 사이트에 올리지 않음)
| 번호 | 받은 날 | ① 시험 | ② 제작 예시 | 지운 날 | 메모 |
|---|---|---|---|---|---|
| 시험견 01 | | 예 | 예/아니요 | | |

- 강아지 이름 · 보호자 이름은 표에 쓰지 않아요. 번호와 카톡 대화방으로만 이어요.
- ②가 '아니요'면 결과를 공개된 곳에 쓰지 않아요. 내부 품질 점검에만 써요.
- 카톡 대화 캡처(동의한 화면)를 번호별로 저장해 둬요. 지울 때 같이 지워요.
- 시험 주문은 실제 제작 흐름을 그대로 거쳐요. 그래서 처리방침 5조와 같은 회사로 가요. 그 밖의 회사가 더해지면 이 문구도 같이 고쳐요.

## 4. "지워 줘"가 오면
1. 그 번호의 사진 · 결과 파일 · 제작 기록을 지워요(탭 4 `./sw` 삭제 명령 또는 운영자 맥 폴더).
2. 공개된 제작 예시가 있으면 내려요.
3. "다 지웠어, 고마워!"라고 답해요. 지운 날을 표에 적어요.
