## 고르면 바꿀 파일
| 무엇 | 지금 | 바꿀 것 |
|---|---|---|
| 공유 미리보기 | `assets/img/og.jpg` | `{안}_og_1200x630.jpg` → 같은 이름으로 덮어쓰기(지금 것은 `_휴지통`) |
| 사이트 아이콘 | `favicon.ico`(48) · `icon-192.png` · `icon-512.png` · `apple-touch-icon.png`(180) · `logo-96.png` | `{안}_icon_512.png`에서 48 · 96 · 180 · 192 · 512 다시 뽑기. A안이면 그대로 |
| 첫 화면 큰 그림 | `assets/img/hero-walk.webp`(720×1280) | `{안}_hero_720x1280.webp` · alt도 같이 바꿈(아래) |
- 앱 아이콘과 사이트 아이콘은 같은 그림이 좋아요. B · C안이면 앱 아이콘을 바꿀지 탭 1과 맞춰요(스토어에 이미 올린 아이콘과 달라지면 검색 결과에서 헷갈려요).

## 구글 검색에 그림이 뜨게 도울 것 (4개 언어 첫 화면 · sitekit HEAD에 같이)
1. **사이트 아이콘(파비콘)** — 구글 검색 결과 이름 옆 동그란 그림. 정사각형 · 48의 배수 · 홈에서 `<link rel="icon">`으로 찾을 수 있게(지금도 있음). 바꾸면 Search Console에서 홈 '색인 생성 요청'.
2. **구조화 데이터** — 홈 `<head>`에 넣기 (CSP는 데이터 블록이라 막지 않아요):
```html
<script type="application/ld+json">
{"@context":"https://schema.org","@graph":[
 {"@type":"WebSite","@id":"https://shallwedog.com/#site","name":"Shall We Dog?","alternateName":"쉘 위 독","url":"https://shallwedog.com/"},
 {"@type":"Organization","@id":"https://shallwedog.com/#org","name":"Shall We Dog?","url":"https://shallwedog.com/","logo":"https://shallwedog.com/assets/img/icon-512.png","email":"hello@shallwedog.com","sameAs":["https://www.instagram.com/shallwedog/"]},
 {"@type":"VideoGame","name":"Shall We Dog?","url":"https://shallwedog.com/","image":"https://shallwedog.com/assets/img/og.jpg","genre":["Simulation","Casual"],"gamePlatform":["iOS","Android"],"inLanguage":["ko","en","ja","es"],"publisher":{"@id":"https://shallwedog.com/#org"}}
]}
</script>
```
   - 스토어 주소가 생기면 VideoGame에 `"sameAs":["App Store 주소","Google Play 주소"]` 더해요. 별점 · 가격(offers)은 넣지 않아요(없는 값 X).
   - 사업자 값(상호 · 주소 · 번호)은 여기 안 넣어요.
3. **og:image:alt · twitter:image:alt** 한 줄 더: 
   - A `게임 속 여러 견종의 3D 강아지가 공원 잔디밭에 모여 있는 모습`
   - B `나무 데크 산책길에 하네스를 한 시바 3D 강아지`
   - C `골든 리트리버 · 비숑 · 진돗개 등 게임 속 견종 10가지 3D 강아지`
4. **첫 화면 그림 alt** (한국어 → T표에 영 · 일 · 스 줄 더함): A `게임 속 견종이 공원에 한자리에 모인 3D 강아지들` · B `산책길 데크를 걷는 시바 3D 강아지 게임 화면` · C `견종 카드로 고르는 3D 강아지들`
5. `sitemap.xml`에 이미지 줄(`xmlns:image`, 홈에 og · hero · lineup) — 선택. 구글 이미지 검색에 도움.
6. 다 넣은 뒤: 구글 [리치 결과 테스트]로 홈 확인 → Search Console 색인 요청(사용자 화면).
