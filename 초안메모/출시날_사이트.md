# 출시 날 사이트 할 일 한 장 (10/27 탭 3)

출시 날(예정 11/16)에 사이트에서 할 일을 순서대로 적었어요. 2~3번은 스토어 주소가 나와야 할 수 있어요. 탭 3이 고치고, 사용자 OK를 받은 뒤 공개해요.

## 순서
| # | 할 일 | 누가 | 확인 방법 |
|---|---|---|---|
| 1 | **검색엔진 막은 것 풀기 (web-007)**<br>확인해 보니 **지금도 막혀 있지 않아요.** `robots.txt` = `Allow: /` + 사이트맵, `noindex`는 404 페이지에만 있어요(의도한 것). 그래서 풀 것은 없어요 | — | `https://shallwedog.com/robots.txt`를 열어 `Allow: /`인지 봐요 |
| 1-1 | 대신 **Search Console에 사이트맵 내기**: 속성 `https://shallwedog.com/` → Sitemaps → `sitemap.xml` 제출 (16개 주소) | 사용자 | '성공' 표시, 며칠 뒤 '색인 생성됨' 수 |
| 2 | **스토어 링크 넣기 (한 · 영 · 일 · 스)** — 첫 화면 4개(`/` · `/en/` · `/ja/` · `/es/`)의 회색 'App Store 곧 출시' · 'Google Play 곧 출시' 버튼을 진짜 링크 버튼으로 바꾸고, 위 작은 글 '곧 출시'를 '지금 받기'로 | 탭 3 (사용자가 링크를 주면) | 4개 언어 첫 화면에서 두 버튼을 눌러 스토어가 열리는지 (아이폰 · 안드로이드 각각) |
| 2-1 | 받을 주소 형식: App Store = `https://apps.apple.com/app/id<숫자>` (나라 빼면 접속한 나라로 열림) · Google Play = `https://play.google.com/store/apps/details?id=<패키지 이름>` (`&hl=ko` 등 언어는 빼도 됨) | 사용자 | App Store Connect '앱 정보 > Apple ID' 숫자 · Play Console 패키지 이름 |
| 2-2 | 같이 고칠 곳: 첫 화면 '출시되면 인스타그램에서 알려드려요' 두 줄 · 메타 설명 '곧 출시해요' · 고객센터의 '스토어 영수증' 안내는 그대로 | 탭 3 | 사이트 전체 '곧 출시' 0건 (점검 스크립트) |
| 3 | **app-ads.txt 확인** — AdMob 게시자 ID로 `/app-ads.txt`를 올렸는지(아직이면 출시 전에) | 탭 3 올림 · 사용자 AdMob 확인 | `https://shallwedog.com/app-ads.txt`가 `google.com, pub-…, DIRECT, f08c47fec0942fa0` 한 줄인지 → 스토어 등록정보 '웹사이트'가 `https://shallwedog.com`인지 → AdMob **앱 > app-ads.txt > 업데이트 확인** (최대 24시간) |
| 4 | **스크린샷 넣을 자리 (web-002)** — 첫 화면 '실제 게임 화면이에요' 칸의 10장(`assets/img/screens/*.webp`)을 **출시 빌드 스크린샷**으로 바꿔요. 같은 이름 · 같은 비율(대부분 600×936, 훈련 · 어질리티 600×1073, 미니게임 600×854)로 주면 글은 그대로예요 | 사용자(스크린샷) · 탭 3(webp로 줄여 넣기) | 4개 언어 첫 화면에서 그림이 바뀌었는지, 폰 너비에서 잘리지 않는지 |
| 4-1 | 문구도 같이: '만들고 있는 화면이라 출시 때는 조금 달라질 수 있어요' → 출시 뒤엔 빼거나 '실제 게임 화면이에요'만 | 탭 3 | — |
| 5 | **공개 뒤 확인** — 4개 언어 첫 화면 · 고객센터 · 삭제 안내가 200으로 열리는지, 보안 설정(CSP) 그대로인지, 바닥 사업자 정보 | 탭 3 | 점검 스크립트(`check2.py`) + https 확인 |

## 탭 3에게 줄 것 (사용자)
1. App Store 앱 주소(또는 Apple ID 숫자)
2. Google Play 패키지 이름
3. AdMob 게시자 ID(`pub-…`) — 아직이면
4. 출시 빌드 스크린샷 10장(위 이름대로, 원하는 것만 바꿔도 돼요)
