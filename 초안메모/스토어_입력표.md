# 스토어 입력표 초안 (10/29 앱 등록용)

전제: 출시 빌드에 Firebase(로그인 · 저장 · 알림 · Analytics · Crashlytics) · AdMob · RevenueCat · Unity 랭킹이 들어간다고 보고 적었어요.
지금 빌드엔 Analytics · Crashlytics · 랭킹 · 로그인이 아직 없어요. 빠지는 게 있으면 그 줄을 지워요.

## 1. 구글 Play '데이터 보안'

공통 답
| 질문 | 답 |
|---|---|
| 데이터를 수집하거나 공유하나요? | 예 |
| 전송 중 암호화? | 예 |
| 데이터 삭제 요청 방법 제공? | 예. 웹 주소 = https://shallwedog.com/delete/ |
| 계정을 만들 수 있나요? | 예 (구글 · 애플 로그인) → 앱 안 삭제 경로 [설정 > 계정 삭제] 필수 |

'공유' = 제3자에게 넘김. 우리 대신 일하는 회사(Firebase · OpenAI · Meshy · Anthropic · RevenueCat · Unity)로 보내는 건 공유가 아니에요. AdMob(Google이 자기 광고에 씀)만 공유로 적어요.

| 데이터 종류 | 수집 | 공유 | 필수/선택 | 목적 |
|---|---|---|---|---|
| 개인 정보 > 이메일 주소 | 예 | 아니요 | 선택 (로그인한 사람만) | 앱 기능, 계정 관리 |
| 개인 정보 > 사용자 ID | 예 | 아니요 | 필수 (랭킹 익명 ID · 결제 ID) | 앱 기능, 계정 관리, 사기 방지 |
| 금융 정보 > 구매 기록 | 예 | 아니요 | 선택 | 앱 기능 |
| 사진 및 동영상 > 사진 | 예 | 아니요 | 선택 (커스텀 주문만) | 앱 기능 |
| 앱 활동 > 앱 상호작용 | 예 | 예 (AdMob) | 필수 | 분석, 광고 |
| 앱 활동 > 기타 사용자 생성 콘텐츠 (강아지 이름 · 주문서 · 랭킹 기록) | 예 | 아니요 | 선택 | 앱 기능 |
| 앱 정보 및 성능 > 비정상 종료 로그 · 진단 | 예 | 예 (AdMob) | 필수 | 분석 |
| 기기 또는 기타 ID | 예 | 예 (AdMob) | 필수 | 광고, 분석, 앱 기능(알림 토큰) |
| 위치 > 대략적인 위치 | 예 (AdMob이 IP로 추정) | 예 (AdMob) | 필수 | 광고 |

'데이터를 일시적으로만 처리' 체크는 하지 않아요(사진을 14일 보관).

## 2. 애플 '앱 개인정보 보호' 라벨

| 분류 > 종류 | 연결됨 | 추적 | 목적 |
|---|---|---|---|
| 연락처 정보 > 이메일 주소 | 예 | 아니요 | 앱 기능 |
| 식별자 > 사용자 ID | 예 | 아니요 | 앱 기능 |
| 식별자 > 기기 ID | 아니요 | **ATT로 묻는다면 예** | 제3자 광고, 분석 |
| 구입 항목 > 구입 내역 | 예 | 아니요 | 앱 기능 |
| 사용자 콘텐츠 > 사진 또는 비디오 | 예 | 아니요 | 앱 기능 |
| 사용자 콘텐츠 > 게임 플레이 콘텐츠 (랭킹 기록) | 예 | 아니요 | 앱 기능 |
| 사용자 콘텐츠 > 기타 (주문서 · 강아지 이름) | 예 | 아니요 | 앱 기능 |
| 사용 데이터 > 제품 상호작용 | 아니요 | 아니요 | 분석, 제3자 광고 |
| 사용 데이터 > 광고 데이터 | 아니요 | ATT로 묻는다면 예 | 제3자 광고 |
| 위치 > 대략적인 위치 | 아니요 | 아니요 | 제3자 광고 |
| 진단 > 충돌 · 성능 | 아니요 | 아니요 | 앱 기능, 분석 |

**정할 것: 아이폰에서 '추적 허용' 창(ATT)을 띄울지**
- 띄움 → 허용한 사람에게 맞춤 광고(광고 수익 ↑). 라벨에 '추적에 사용되는 데이터'가 생기고, 앱에 추적 이유 문구가 필요.
- 안 띄움 → 맞춤 아닌 광고만. '추적' 칸이 비어 깔끔.
- 처리방침 8조는 '띄움' 기준으로 적었어요. 안 띄우면 그 문장을 '맞춤 광고는 보이지 않아요'로 바꿔요.
